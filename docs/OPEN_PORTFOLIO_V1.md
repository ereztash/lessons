## Shared publication gate

A repository reaches "spotlight-ready" only when all five are true:

1. **Legal** — license and third-party/data provenance are explicit.
2. **Stranger value** — a new reader understands the job in <= 60 seconds.
3. **Reproduction** — a new reader can observe the core behavior in <= 10 minutes.
4. **Claim integrity** — strong claims name their evidence floor and current limit.
5. **Contribution surface** — the repository says how to use, report, fork, or contribute.

## Portfolio thesis

Across the strongest projects, the recurring contribution is not a specific application domain.

> Build systems in which AI is not allowed to convert an attractive inference into product truth merely because the system ran successfully.

That pattern appears in chess, language input, evidence mining, RAG intake, software assurance, product sensemaking, and cognitive-offloading research.
