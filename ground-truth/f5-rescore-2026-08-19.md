## 1. F5, mechanically

`F5 = external consumer`, true if **any** of:

- **(a)** a deployment config (`vercel.json`, `netlify.toml`, `fly.toml`, `Dockerfile`,
  `render.yaml`, a `deploy` workflow) **and** a live non-repo URL in the README
- **(b)** a document addressed to a real recipient (`docs/*PILOT*`, `*CLIENT*`, `*INVESTOR*`,
  `*LAUNCH*`, `*READINESS*`, `*OFFER*`, `docs/*manager*`)
- **(c)** a published release tag

`R = current`: last commit ≤ 30 days before 2026-08-19, measured across **all refs**.

**The new tier rule.** The old rule was `A: 3–4/4 · B: 1–2/4 · C: 0/4 · D: non-software`. The new
rule keeps the F-count ordering but gates the top tier on serving someone, now:

```
not software              -> D   inert
F5 AND R                  -> A   operating
F_count >= 3              -> B   managed apparatus, no live consumer
F_count 1-2               -> C   prototype
F_count 0                 -> D
```

The `not software` test (≥2 source files or a manifest) reproduces mechanically what the n=25 scan
assigned by hand, so the old/new comparison isolates F5 rather than my re-implementation.

## 3. Four things the re-score surfaced

**3.1 `groundstate-protocol` and `ground-state-protocol` are different repositories.**
The public `groundstate-protocol` has 311 commits, 55 branches, and was committed to 17 days ago.
The private `ground-state-protocol` — the one deep-dived in Phase 1 and cited throughout
`/research/groundstate-protocol/` — has 43 commits and is 92 days dormant. There are two more
private copies (`ground-state-protocol-32679ce4`, `-02aba105`). Every claim in the repo's research
folder needs re-checking against which of these it actually describes.

**3.2 Default-branch dormancy understates activity.** The n=25 scan measured the default branch.
Across all refs, `Contradiction_loss` is 77 days dormant rather than 282, `keepath` 74 rather than
231, `CandiApp` 205 rather than 273. This compounds with `claude-branch-as-default-branch`: where
the operator works on branches, a default-branch reading calls a live repo dead. Both figures are
now in the data file.

**3.3 `Contradiction_loss` has 42 commits, not 2.** The scan recorded "2 human commits" and Tier D
"non-software". It has 42 commits across 10 branches and Python source. The scan was wrong about
this repo in the same direction as everything else — but here it under-rated rather than over-rated.

**3.4 The portfolio is ~40 repos, not 30.** `list_repos` returns 40. Nine were never scanned:
`pre-call` (**pushed today, 2026-08-19**), `proofminer` (3 days), `kol_kore`,
`cognitive-sovereignty-ai-paper`, `dod-validator`, `_crm` (the source of the `CRM_Google_ai`
mirror), `ex2`, and the two `ground-state-protocol-*` copies. They are **not** scored here — the
task was the 30 in the index — but `pre-call` is more recently active than 29 of the 31 repos that
were scored.

## 4. What F5 is actually detecting

Of 31 repos, 2 have an external consumer and current work. Nine of the thirteen old-Tier-A repos
have the full F1–F4 apparatus — a real dependency, human commits, PRs, a docs folder — and nothing
consuming them. `ampaign-craft` has 939 source files, 199 PRs and 77 branches, and `main` has not
moved in 101 days.

That is the portfolio's actual shape, and F1–F4 could not express it because all four of its
features are things an AI-paired operator produces in an afternoon.

## 5. Why this table is not evidence that F5 works

**On the 10 ground-truth repos, F5 agrees almost perfectly with the label — and that proves
nothing**, because ground-truth `A` is *defined* as `serving ∧ current ∧ executable` and F5 is a
mechanical proxy for `serving`. Scoring F5 against those labels is scoring a definition against
itself. This is the same circularity flagged in `results-2026-08-19.md` §5.1, and it is why no
accuracy figure appears in this document.

What this re-score legitimately provides:

- a **measurement** — F1–F5 re-derived from source for all 31 repos, replacing scan-level inference
- a **hypothesis** — that gating the top tier on a consumer produces a truer portfolio picture
- **twelve repos of new information** — the 20 repos outside the ground-truth set had never been
  measured on any consumer signal

What it does not provide is validation. That requires a test whose answer is not yet known, which
is `prediction-2026-08-19.md`.
