# 90-Day Go-To-Market Plan

## ICP priority order

1. **Israeli AI builders** (primary) — direct warm network, Hebrew content resonates, high repo creation rate, underserved by English-only tooling
2. **Lovable power users** (global) — publish-button satisfiability is their exact pain, Lovable community is active on Discord and X
3. **Claude Code early adopters** (global) — already understand the `claude/*` branch pattern, will recognize the operator-absent diagnosis immediately
